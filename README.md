# Power BI Injury Analytics Dashboard

## 📊 Project Overview
This Power BI project analyzes injury patterns, recovery trends, workload impact,
financial cost, and geographic distribution across players and clubs.

The dashboards help stakeholders understand injury risk, recovery efficiency,
and cost drivers.

---

## 🧩 Dashboards Included

### 1. Executive Overview
- Total injuries and injured players
- Average recovery days
- Total treatment cost
- Injury trends over time

### 2. Injury Analysis
- Most common injury types
- Injury severity breakdown
- Injuries by body area
- Monthly injury trends

### 3. Recovery & Workload
- Recovery rate and days to recovery
- High workload injury percentage
- Treatment outcomes
- Workload vs recovery relationship

### 4. Financial Impact
- Total and average treatment costs
- Cost by injury type and body area
- Monthly treatment cost trends
- Cost comparison across sports

### 5. Geographic View
- Injuries by country and region
- Recovery vs treatment cost by location
- Regional injury distribution

---

## 🛠 Tools & Technologies
- Power BI Desktop
- DAX measures
- Power Query
- Interactive slicers and filters
- Data modeling
